# Contributing & Topic Requests

Welcome to **Cyber Security Notes** by [DaddyZyn (DRAXO.dev)](https://github.com/DaddyZyn). This repository is dedicated to providing high-quality, low-level technical documentation for learners, researchers, and systems engineers.

---

## 💡 How to Request a New Topic
Want a topic covered or expanded?
1. Head over to the **[Issues tab](https://github.com/DaddyZyn/Cyber-security-notes/issues)**.
2. Click **New Issue** and select **💡 Request a New Topic / Module**.
3. Detail what concept, architecture, or protocol you want documented.

---

## 🛠️ How to Contribute Documentation
We welcome community contributions, improvements, and technical corrections:

1. **Fork the Repository**: Click "Fork" in the top right corner.
2. **Create a Topic Branch**:
   ```bash
   git checkout -b topic/your-topic-name
   ```
3. **Structure Your Module**:
   * Create a new folder under `topics/` named `XX-topic-slug/` (e.g., `topics/05-process-memory-internals/`).
   * Add a comprehensive `README.md` with deep technical explanations, diagrams, and packet/memory layouts.
4. **Link in Root Index**: Add your module to the table in the root `README.md`.
5. **Open a Pull Request**: Submit your PR with a clear summary of the additions.

---

## 📐 Guidelines
* **No Fluff**: Get straight to the technical mechanics, packet headers, OS APIs, and threat models.
* **Accuracy First**: Double-check RFC references, WinAPI definitions, and cryptographic primitives.
* **Readable Diagrams**: Use clean ASCII flowcharts and markdown tables.
